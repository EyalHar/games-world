# עולם המשחקים

## משחקים
- **משחק האסוציאציות** – גוררים פיות ושדון ומנחשים את המילה הסודית.
- **ארץ עיר** – משחק מרובה משתתפים, כל שחקן מהמכשיר שלו (באותה רשת ביתית). התשובות נבדקות אוטומטית על ידי Gemini.

## הפעלה

### שרת (פורט 4403)
```bash
cd server
npm install
npm run dev
```

### לקוח (פורט 5406)
```bash
cd client
npm install
npm start
```

פתחו את הדפדפן בכתובת: http://localhost:5406

## הגדרת הבדיקה האוטומטית בארץ עיר (חינמי)
1. צרו מפתח חינמי ב-[Google AI Studio](https://aistudio.google.com/apikey).
2. הדביקו אותו בקובץ `server/.env`:
   ```
   GEMINI_API_KEY=המפתח-שלכם
   ```
3. הפעילו מחדש את השרת.

בלי מפתח (או כשהמכסה החינמית נגמרת) המשחק ממשיך לעבוד: כל תשובה שמתחילה באות הנכונה מתקבלת, והשחקנים יכולים לפסול תשובות בהצבעה.

> שימו לב: במסלול החינמי Google רשאית להשתמש בתוכן הבקשות לשיפור המודלים. נשלחות רק התשובות והתחומים — לא שמות השחקנים.

## משחק מכמה מכשירים
פותחים חדר מהמחשב שעליו רץ השרת. בלובי מוצג קישור עם כתובת המחשב ברשת הביתית (למשל `http://192.168.1.20:5406/eretz-ir?room=1234`), ושאר השחקנים נכנסים דרכו מהטלפון. אם החיבור לא עובד, ייתכן שחומת האש של Windows חוסמת את הפורטים 4403 ו-5406.
